11.1 下山经峭壁 / 水渠出兴记 → 回中山马鞍岛 — 中高 · 下行陡

路线一句话：拉胡线因拉胡村得名，现多从百木洋 · 兴记农家乐进出。 正穿常见为兴记 → 水渠 → 拉胡峭壁 → 水底山（约 1280 m）→ 下山； 反穿多从大榕树 / 龙岩寺盘山公路缺口进，经 A9 垭口、水底山，再经峭壁、树林、水渠出兴记。 驴友口中的烂尾楼在水底山附近下山岔路一带，是常见日落 / 云海与过夜点；岔路易走偏，见下文。
命名对照：小红书等攻略里终点侧常写大王殿或大王庙（同一带俗称，搜哪个以高德能到为准）； 精华线反穿常见写法是「龙岩寺登山口 → 斧头石 → 大王殿」，约 12.5 km / 累计爬升约 1000 m。 也有人按约 15 km 环线写「龙岩寺 → 水底山顶 → 斧头石 → 大王庙」。 本趟仍以兴记进出 + 水底山侧烂尾楼过夜为主线；斧头石草甸风景口碑好（有人比武功山草甸感），是否绕过去看体能与轨迹再定。
正穿 / 反穿：白天走反穿树荫多、少暴晒；夜爬多建议正穿。本趟日间反穿进山，方向与此一致。 离线 GPS 轨迹行前必下（两步路 / 六只脚等），山里信号不稳。

10.31 出发 · 拉胡线反穿进山 · 烂尾楼过夜

当日时间轴（约，计划估算）

到烂尾楼要多久：大榕树 / 龙岩寺登山口 → 水底山侧烂尾楼， 有经验约 3–4.5 h 纯走；新手 + 过夜包约 4.5–6.5 h（含短休、拍照）。 精华线反穿全程约 12.5 km / 爬升约 1000 m；本趟若走完出兴记，全程多落在约 15–18 km。 十月底广东日落约 17:40–18:00；多数节奏下午 14:30–16:00 可到过夜点， 不必 06:30 那么早出门——马鞍岛约 07:30–08:30 出发通常够用； 新手偏慢、想多留拍照 / 天黑前缓冲，可再早一点；最晚不宜拖过约 08:30（再晚易顶黑安顿）。 本夜是周末：约 3:00–3:30 起常有夜爬队伍到顶，吵到难睡——耳塞、预期先降一档。

  1. 约 07:30–08:30中山马鞍岛出发（可晚一点；想宽裕可更早）；最后检查饮水、头灯、离线轨迹
  2. 约 08:00–11:00自驾 马鞍岛 → 惠东兴记农家乐（约 2–2.5h，视路况）
  3. 约 10:00–12:00兴记停车休整；接驳至大榕树 / 龙岩寺登山口（包车或约车；说清「龙岩寺」还是「半山腰」）
  4. 约 11:00–13:30大榕树 → A9 垭口一带（约 1.5–2.5h；前段机耕 / 山径；雨天极难走）
  5. 约 13:00–15:30A9 → 水底山冲顶与草甸；午饭、补水、拍照（约 1000 m 以上易浓雾，天气变化快）
  6. 约 14:30–16:30水底山侧切至烂尾楼（纯走约 20–40min；岔路左切，勿沿石溪直下）
  7. 约 15:00–16:30多数可到；日落 / 云海前后安顿过夜；早睡留电——凌晨夜爬可能吵醒
推荐自驾

车停兴记 · 接驳去起点

车停反穿终点兴记农家乐，再打车 / 包车到大榕树 / 龙岩寺进山；次日下山直接取车，省得终点再倒腾。登山口很多，跟司机说清要龙岩寺还是半山腰，别停错口。

VS
备选

车停大王殿 / 龙岩寺 · 终点再回

有人导航惠东县「大王殿」（亦称大王庙）停车后打车去登山口；或车停龙岩寺停车场直接进山，出兴记后再约车回取车。终点找车不如前者省心。

出发与停车

  1. 中山马鞍岛（出发点）

    自行导航 · 不链

  2. 惠东 · 兴记农家乐（停车）

    高德好搜百木洋一带

    定位：惠东县多祝 / 百木洋一带，公开活动常用「兴记农家乐」「百木洋兴记农家乐」。 附近还有一亩三分地、强记等农家乐，认准停车后再进山。
    停车：上午到即可（周末与节假日车位仍可能紧，不必为抢位太早出门）；兴记侧农家乐是否收费以现场为准。 活动文案写兴记旁即「世外桃源农庄农副产品」；两步路称对面驴友驿站可提前联系芳姐留车位。 Trip.com 有文写芳姐是兴记老板娘，另有攻略把她挂在世外桃源侧——身份公开源冲突，到店再问。
    大王殿 / 大王庙侧参考价：有攻略写村民收费约 15 元 / 车（当日），重装过夜约 20 元 / 车；以现场为准。 大王殿 ↔ 登山口约有 6 km 水泥盘山路，村民载客常见约 20 元 / 人（可作接驳议价参考）。
    吃饭 / 过夜：下山后兴记一带常见农家饭（有攻略写人均约 40）；冲凉与室内房以现场为准。 向野行写兴记可扎营，室内住宿更常写提前订「世外桃源农庄」（联系芳姐）。公开电话与房价未查到。

  3. 许屋洋（备用搜点）

    兴记不好搜时

    部分攻略写导航「惠东县多祝镇许屋洋」可到登山口附近乡村路。优先仍搜兴记；此为备用关键词。

反穿进山

  1. 大榕树 / 龙岩寺（反穿起点）

    反穿进山口

    拉胡精华线反穿常见从龙岩寺下方盘山公路「大榕树缺口」进。 高德搜「龙岩寺」（惠东大南山）；大巴往往上不到真正缺口，还可能要再走一段水泥路。 自驾轿车盘山路窄、坡大，会车提前鸣笛。 登山口不止一个：接驳时务必说清停龙岩寺还是半山腰，别被拉到别的口。
    进山后大致：大榕树 → A9 垭口 → 水底山 →（切烂尾楼过夜）→ 次日再经拉胡峭壁、树林、水渠出兴记。 也有轨迹写龙岩寺 → 斧头石 → 大王殿；本趟过夜点按水底山侧烂尾楼。

  2. A9 垭口 · 水底山

    最高点约 1280 m草甸风大

    水底山是拉胡线制高点，山脊草甸开阔，十月底草色偏金黄；天气好时日落、朝霞、云海都常见，斧头石一带草甸也有口碑。 冲顶前有较长陡坡，反穿时体能要留余量给过夜负重。 约 1000 m 以上常遇浓雾，能见度接近零；天气变化快，刚下雨也可能突然放晴——轨迹与防风层别省。 山脊段遮挡少，防晒 + 防风层都带上。 露营区无水源，饮用水全部自带；按约 2.5–3 L / 人起跳，过夜再酌加；季节性小溪勿依赖。本次饮水见「物品清单 · 个人准备」。

    山野点位 · 不链导航

  3. 住宿 · 烂尾楼（山上废弃房子）

    过夜点非正规民宿

    驴友俗称烂尾楼，在水底山附近下山岔路一带，也是常见日落 / 云海观景点。 自登山口到此：有经验约 3–4.5h、新手过夜包约 4.5–6.5h（含休）；水底山再切过来通常半小时内。 到此附近岔路往左切（勿沿石溪一直直下，易走进溯溪岔路）；天黑前务必确认轨迹与标记。
    过夜实话：不是正规住宿——墙体与楼板状态不明、可能漏风漏雨、夜里偏冷且手机信号常弱或无。 露营点无水源，喝的水都得背上来。 结伴为佳；带头灯备用电、应急毯 / 睡袋、足够饮水与干粮；地板潮湿时垫防潮垫。
    周末噪音：攻略普遍劝周六日、节假日少在山上露营——夜爬人多，约 3:00–3:30 陆续到顶，吵到难睡；本趟正好周末，带耳塞、别期待安睡。 不建议独行过夜；若预报大风大雨，改下山住农家乐更稳妥（雨天山路极难走）。

    山野点位 · 不链导航

11.1 下山出兴记 · 回马鞍岛

当日时间轴（约）

  1. 约 06:30–07:30起床收装（若被夜爬吵醒可能更早）；简单早餐；检查头灯电量（林段可能偏暗）
  2. 约 07:30–12:00烂尾楼 → 拉胡峭壁 → 树林 / 水渠 → 兴记（视体能 4–6h）
  3. 约 12:00–13:30兴记休整、可选农家午饭；换干净衣服
  4. 约 13:30–16:00自驾 兴记 → 中山马鞍岛（约 2–2.5h）
计划 · 走完反穿

经拉胡峭壁出兴记

反穿精华：下行经过拉胡峭壁（正穿是上行拉绳，反穿变下行，湿滑时更吃鞋底与手套）。出树林后接水渠平路回兴记。

VS
体力不支时

烂尾楼 → 机耕路回兴记

环线常见下撤：烂尾楼切机耕路回兴记，少走一段峭壁。夜里或疲劳时优先保安全，不必硬走满反穿。

  1. 拉胡峭壁 · 树林 · 水渠

    手套必带绳段慢行

    峭壁段有拉绳陡坡，反穿时重心放低、确认落脚点；恐高者可改机耕路下撤。 水渠段接近尾声，多为平路，但腿已经软——别赶时间在湿石上滑倒。 全程垃圾带走；山里无垃圾桶。

    山野路段 · 不链导航

  2. 兴记农家乐（取车 / 休整）

    下山后可简单吃饭、冲凉（以店家当日服务为准）。取车回中山前补油、补水。

  3. 终点 · 中山马鞍岛

    自行导航 · 不链

物品清单（新手采购向）

按过夜反穿定制。价格带为国内常见网购 / 迪卡侬量级，够用即可，不必一次配齐重装顶配。

证件 / 车 / 导航

  • 身份证
  • 驾驶证、行驶证
  • 离线地图 + GPS 轨迹（两步路 / 六只脚等，行前下好「拉胡线」「大榕树反穿」；强烈建议离线）
  • ETC / 现金小额（接驳约 20 元级 / 人、停车 15–20 元级参考）
  • 车载充电器、手机支架
  • 手机防水袋（出汗、露水、小雨都用得上；迪卡侬 / 淘宝几块到二十）

鞋袜 · 衣物分层

  • 防滑登山鞋（鞋头偏硬，防磕石；勿普通运动鞋）
  • 美利奴羊毛袜或中长筒排汗袜两双（勿纯棉；一双路上穿，一双过夜换）
  • 旧袜子一双：鞋底抓地不够时套鞋外增阻，下山也少脏鞋
  • 速干内衣 + 中层保暖（薄抓绒优先）
  • 防风软壳或冲锋衣外壳
  • 夜间冷可带轻薄羽绒服或加厚抓绒——广东 10 月底多数情况抓绒 + 防风够用；怕冷、山脊风大或烂尾楼漏风再上羽绒服，不必按北方冬装备
  • 速干长裤；一次性内裤即可——就一夜，不必另背整套换洗衣物
  • 拖鞋一双（营地 / 过夜换脚）
  • 薄手套（抓绳、防刮）；可选触屏款

背包 / 水 / 灯电

  • 双肩包 28–40L（过夜反穿：睡袋+防潮垫+衣物+水食+头灯；见下方选购 tip）
  • 饮水（露营区无水源；至少 2.5–3 L / 人起，过夜再加；勿指望小溪）
  • 本次个人饮水组合见下方「食物 · 个人准备」
  • 头灯 + 备用电池 / 第二光源
  • 充电宝（≥10000 mAh，冷天电掉得快）
  • 登山杖一对：下山省膝；反穿下行更建议带
  • 轻量雨衣 / 背包防雨罩（包本身最好自带防雨罩）
  • 垃圾袋（全程垃圾带走）
  • 买包看三点：透气背负、硬一点的腰带（负重上胯）、防雨罩；迪卡侬 / 牧高笛入门款够用

过夜

  • 睡袋或厚应急毯 + 防潮垫（烂尾楼地面潮）
  • 湿巾、纸巾
  • 耳塞（周末夜爬约 3 点到顶，吵到难睡）
  • 哨子 / 应急箔毯：体积小，过夜安心一点

食物 · 常规建议

  • 高热量干粮：面包、牛肉干、能量棒、巧克力、电解质粉
  • 露营区无水源：优先免煮 / 即食（面包、罐头；自热饭需额外带水）；热水壶可选，固体燃料灶非必须
  • 盐分零食 / 坚果：补盐、扛饿（饮水仍见「背包 / 水」卡）
  • 午饭后上山时，也可只备晚餐 + 次日早餐，不必另背全天午饭

食物 · 个人准备

  • 午饭后上山：只备晚餐 + 次日早餐
  • 馒头 ×2、卤牛肉一份、紫甘蓝一颗、瓜子一包
  • 水：矿泉水 1.5 L + 椰子水 1 + 汽水/运动饮料 1（约 2–2.5 L+）
  • 可选再加 500 ml：刷牙 / 简单擦洗
  • 免煮即食；不必带灶具 / 自热饭

药品 / 急救

  • 创可贴、水泡贴（下山磨脚常见）
  • 止痛药、肠胃药、个人常备药
  • 碘伏棉棒、绷带少量
  • 感冒 / 退烧药按需：过夜受凉或队友不适时有用，体积小可备一板

鞋与袜： 要不要上迪卡侬 MH100/MH500、凯乐石一类更好的鞋，跟重不重装没关系——有预算、有能力就往上换一档更踏实； 现有鞋若抓地够用、鞋头偏硬能防磕石，这趟继续穿也没问题。 尺码按日常脚长买即可，不必死守「大一码」；穿着厚袜时后跟大约一指空隙较舒服。 袜子比鞋更常被低估：优先美利奴羊毛袜（排汗、不起皱、少水泡）；抓地不够的湿滑段，可把旧袜套在鞋外增加摩擦力。

新手怎么买（够用档）： 背包选 28–40L、有透气背板 + 腰带的（迪卡侬 / 牧高笛等约百元级起；过夜睡袋+垫+水食塞满后 25L 偏紧，40L 以上又容易空荡晃）； 头灯买能调焦、续航标称 10h+ 的入门款即可； 杖选可折叠外锁，新手先体验再决定要不要碳杖； 睡袋按「舒适温度」留余量即可；十月底山顶夜间多在十来度，风大或漏风体感更低，不必按严冬睡袋备。 整套新购控制在「能安全走完」比「品牌齐全」优先。

行前预约清单

理想版 vs 备选版

计划走法

  1. 车停兴记，接驳大榕树 / 龙岩寺反穿进山
  2. 经 A9、水底山，傍晚切烂尾楼过夜（备足水、耳塞）
  3. 次日经拉胡峭壁、水渠出兴记取车
  4. 下午回中山马鞍岛

更稳妥的备选

  1. 风力降雨偏大：取消过夜，改兴记环线当日往返（日间反穿更荫凉）
  2. 体力吃紧：烂尾楼走机耕路下撤，不强穿峭壁；或仿部分驴友从水底山走中间线路下撤近龙岩寺下方出口
  3. 受不了周末夜爬噪音：改平日过夜，或山下兴记 / 世外桃源农庄（芳姐；电话房价待确认）
  4. 新手结伴有经验者领路；独行优先日间环线

注意事项

  • 难度：精华线反穿约 12.5 km / 爬升约 1000 m；走完出兴记多落在约 15–18 km、爬升千米级。反穿时峭壁变下行，比正穿更吃鞋底与心理；白天反穿树荫多、少暴晒，夜爬多建议正穿。纯新手建议先日间环线，再考虑过夜反穿。
  • 十月底天气：山脊风大、昼夜温差明显；约 1000 m 以上易浓雾，天气变化快。防风层必带，过夜保暖以抓绒为主、怕冷再加轻薄羽绒。雨天山路极难走，石面湿滑时绳段更慢——行前务必看预报。
  • 信号与导航：山里常无信号，强烈建议行前下载离线 GPS 轨迹；烂尾楼附近岔路认清左切，勿沿石溪直下误入溯溪。接驳说清龙岩寺 / 半山腰，别停错登山口。
  • 水：大南山露营区无水源，饮用水全部自带，勿指望小溪；常规至少约 2.5–3 L / 人。本次个人组合见「物品清单 · 个人准备」。
  • 过夜与噪音：废弃建筑结构与卫生条件未知；结伴、留足电量与用水。本趟周六日，约 3:00–3:30 夜爬到顶嘈杂难睡——耳塞自备；能改平日过夜更安静。身体不适或天气转坏果断下撤。
  • 停车与接驳：兴记上午到即可（周末车位仍可能紧，不必为抢位 06:30 出门）；大王殿 / 大王庙侧村民收费常见约 15（当日）/ 20（过夜）元 / 车，盘山接驳约 20 元 / 人，均以现场为准。盘山路窄，沟通好等候点。
  • 环保（LNT）：无垃圾桶，垃圾全部带走，不留痕迹。
