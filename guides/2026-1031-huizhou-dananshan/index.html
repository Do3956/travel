路线一句话：拉胡线因拉胡村得名，现多从百木洋 · 兴记农家乐进出。 正穿常见为兴记 → 水渠 → 拉胡峭壁 → 水底山（约 1280 m）→ 下山； 反穿多从大榕树 / 龙岩寺盘山公路缺口进，经 A9 垭口、水底山，再经峭壁、树林、水渠出兴记。 驴友口中的烂尾楼在水底山附近下山岔路一带，是常见日落点与过夜点；岔路易走偏，见下文。

10.31 出发 · 拉胡线反穿进山 · 烂尾楼过夜

当日时间轴（约，计划估算）

  1. 约 06:30–07:00中山马鞍岛出发；最后检查水、头灯、离线轨迹
  2. 约 07:00–09:30自驾 马鞍岛 → 惠东兴记农家乐（约 2–2.5h，视路况）
  3. 约 09:30–10:30兴记停车休整；接驳至大榕树 / 龙岩寺登山口（包车或约车，约 20–40min）
  4. 约 10:30–13:00大榕树 → A9 垭口一带（前段机耕 / 山径，匀速热身）
  5. 约 13:00–16:00A9 → 水底山冲顶与草甸；补水、拍照，留意天气与风
  6. 约 16:00–17:30水底山侧切至烂尾楼；天黑前安顿过夜
  7. 晚间烂尾楼过夜；早睡，留电与头灯电量给次日下山
推荐自驾

车停兴记 · 接驳去起点

车停反穿终点兴记农家乐，再打车 / 包车到大榕树 / 龙岩寺进山；次日下山直接取车，省得终点再倒腾。

出发与停车

  1. 中山马鞍岛（出发点）

    自行导航 · 不链

  2. 惠东 · 兴记农家乐（停车）

    高德好搜百木洋一带

    定位：惠东县多祝 / 百木洋一带，公开活动常用「兴记农家乐」「百木洋兴记农家乐」。 附近还有一亩三分地、强记等农家乐，认准停车后再进山。
    停车：尽量上午到，周末与节假日车位紧；农家乐是否收费以现场为准。 活动文案写兴记旁即「世外桃源农庄农副产品」；两步路称对面驴友驿站可提前联系芳姐留车位。 Trip.com 有文写芳姐是兴记老板娘，另有攻略把她挂在世外桃源侧——身份公开源冲突，到店再问。
    吃饭 / 过夜：下山后兴记一带常见农家饭（有攻略写人均约 40）；冲凉与室内房以现场为准。 向野行写兴记可扎营，室内住宿更常写提前订「世外桃源农庄」（联系芳姐）。公开电话与房价未查到。

  3. 许屋洋（备用搜点）

    兴记不好搜时

    部分攻略写导航「惠东县多祝镇许屋洋」可到登山口附近乡村路。优先仍搜兴记；此为备用关键词。

反穿进山

  1. 大榕树 / 龙岩寺（反穿起点）

    反穿进山口

    拉胡精华线反穿常见从龙岩寺下方盘山公路「大榕树缺口」进。 高德搜「龙岩寺」（惠东大南山）；大巴往往上不到真正缺口，还可能要再走一段水泥路。 自驾轿车盘山路窄、坡大，会车提前鸣笛。
    进山后大致：大榕树 → A9 垭口 → 水底山 →（切烂尾楼）→ 次日再经拉胡峭壁、树林、水渠出兴记。

  2. A9 垭口 · 水底山

    最高点约 1280 m草甸风大

    水底山是拉胡线制高点，山脊草甸开阔，十月底草色偏金黄。冲顶前有较长陡坡，反穿时体能要留余量给过夜负重。 山脊段遮挡少，防晒 + 防风层都带上。沿途可靠水源少，按 2.5–3 L / 人备水更稳；季节性小溪勿依赖。

    山野点位 · 不链导航

  3. 住宿 · 烂尾楼（山上废弃房子）

    过夜点非正规民宿

    驴友俗称烂尾楼，在水底山附近下山岔路一带，也是常见日落观景点。 到此附近岔路往左切（勿沿石溪一直直下，易走进溯溪岔路）；天黑前务必确认轨迹与标记。
    过夜实话：不是正规住宿——墙体与楼板状态不明、可能漏风漏雨、夜里偏冷且手机信号常弱或无。 结伴为佳；带头灯备用电、应急毯 / 睡袋、足够饮水与干粮；地板潮湿时垫防潮垫。 不建议独行过夜；若预报大风大雨，改下山住农家乐更稳妥。

    山野点位 · 不链导航

11.1 下山出兴记 · 回马鞍岛

当日时间轴（约）

  1. 约 06:30–07:30起床收装；简单早餐；检查头灯电量（林段可能偏暗）
  2. 约 07:30–12:00烂尾楼 → 拉胡峭壁 → 树林 / 水渠 → 兴记（视体能 4–6h）
  3. 约 12:00–13:30兴记休整、可选农家午饭；换干净衣服
  4. 约 13:30–16:00自驾 兴记 → 中山马鞍岛（约 2–2.5h）
计划 · 走完反穿

经拉胡峭壁出兴记

反穿精华：下行经过拉胡峭壁（正穿是上行拉绳，反穿变下行，湿滑时更吃鞋底与手套）。出树林后接水渠平路回兴记。

VS
体力不支时

烂尾楼 → 机耕路回兴记

环线常见下撤：烂尾楼切机耕路回兴记，少走一段峭壁。夜里或疲劳时优先保安全，不必硬走满反穿。

  1. 拉胡峭壁 · 树林 · 水渠

    手套必带绳段慢行

    峭壁段有拉绳陡坡，反穿时重心放低、确认落脚点；恐高者可改机耕路下撤。 水渠段接近尾声，多为平路，但腿已经软——别赶时间在湿石上滑倒。 全程垃圾带走；山里无垃圾桶。

    山野路段 · 不链导航

  2. 兴记农家乐（取车 / 休整）

    下山后可简单吃饭、冲凉（以店家当日服务为准）。取车回中山前补油、补水。

  3. 终点 · 中山马鞍岛

    自行导航 · 不链

物品清单（新手采购向）

按过夜反穿定制。价格带为国内常见网购 / 迪卡侬量级，够用即可，不必一次配齐重装顶配。

证件 / 车 / 导航

  • 身份证
  • 驾驶证、行驶证
  • 离线地图 + 轨迹（两步路 / 六只脚等，行前下好「拉胡线」「大榕树反穿」类轨迹）
  • ETC / 现金小额（接驳、农家停车）
  • 车载充电器、手机支架
  • 手机防水袋（出汗、露水、小雨都用得上；迪卡侬 / 淘宝几块到二十）

鞋袜 · 衣物分层

  • 防滑登山鞋（鞋头偏硬，防磕石；勿普通运动鞋）
  • 美利奴羊毛袜或中长筒排汗袜（勿纯棉；再备一双过夜换）
  • 旧袜子一双：鞋底抓地不够时套鞋外增阻，下山也少脏鞋
  • 速干内衣 + 薄抓绒 / 轻薄羽绒服（山脊风大，夜里更冷）
  • 防风软壳或冲锋衣外壳
  • 速干长裤；换洗衣物放车里即可
  • 薄手套（抓绳、防刮）；可选触屏款

背包 / 水 / 灯电

  • 双肩包 25–35L（过夜负重；腰臀腰带要紧）
  • 饮水 2.5–3 L / 人（软壶 + 硬瓶组合方便）
  • 头灯 + 备用电池 / 第二光源
  • 充电宝（≥10000 mAh，冷天电掉得快）
  • 登山杖一对：下山省膝；反穿下行更建议带
  • 轻量雨衣 / 背包防雨罩
  • 垃圾袋（全程垃圾带走）

过夜 / 食物 / 药

  • 睡袋或厚应急毯 + 防潮垫（烂尾楼地面潮）
  • 高热量干粮：面包、牛肉干、能量棒、巧克力、电解质粉
  • 热水壶可选；固体燃料灶非必须
  • 创可贴、水泡贴、止痛药、肠胃药、个人常备药
  • 碘伏棉棒、绷带少量
  • 湿巾、纸巾、头灯备用电
  • 哨子 / 应急箔毯：体积小，过夜安心一点

鞋与袜（短途实测向）： 短途过夜线不必强上迪卡侬 MH100/MH500、凯乐石一类重装长线鞋——已买的鞋若防滑够用、鞋头偏硬能防磕石、透气尚可，就继续穿练。 尺码按日常脚长买即可，不必死守「大一码」；穿着厚袜时后跟大约一指空隙较舒服。 袜子比鞋更常被低估：优先美利奴羊毛袜（排汗、不起皱、少水泡）；抓地不够的湿滑段，可把旧袜套在鞋外增加摩擦力。

新手怎么买（够用档）： 背包选有腰带的 25–35L（迪卡侬 / 牧高笛等约百元级起）； 头灯买能调焦、续航标称 10h+ 的入门款即可； 杖选可折叠外锁，新手先体验再决定要不要碳杖； 睡袋按「极限温度」留余量，十月底山顶按 5–10℃ 体感备更稳。 整套新购控制在「能安全走完」比「品牌齐全」优先。

行前预约清单

  • 看天气预报（风力、降雨）；大风大雨取消过夜，改当天环线或改期
  • 下载离线地图 + 拉胡线 / 大榕树反穿轨迹；标记烂尾楼岔路
  • 约伴（过夜不建议独行）；互留紧急联系人
  • 确认兴记停车与接驳大榕树方式（包车价待定，可到村口再问）
  • 充电宝、头灯满电；前一晚装包称重试背
  • 告知家人大致进出时间与预计下山点（兴记）

理想版 vs 备选版

计划走法

  1. 车停兴记，接驳大榕树反穿进山
  2. 经 A9、水底山，傍晚切烂尾楼过夜
  3. 次日经拉胡峭壁、水渠出兴记取车
  4. 下午回中山马鞍岛

更稳妥的备选

  1. 风力降雨偏大：取消过夜，改兴记环线当日往返
  2. 体力吃紧：烂尾楼走机耕路下撤，不强穿峭壁
  3. 新手结伴有经验者领路；独行优先日间环线
  4. 下山太晚 / 不睡烂尾楼：山下兴记吃饭休整，室内过夜优先问旁侧世外桃源农庄（芳姐；电话房价待确认）

注意事项

  • 难度：拉胡线整体偏高强度（约 15–18 km、爬升千米级）。反穿时峭壁变下行，比正穿更吃鞋底与心理；纯新手建议先日间环线，再考虑过夜反穿。
  • 十月底天气：山脊风大、昼夜温差明显；带防风层与过夜保暖。有雨雾时石面湿滑，绳段更慢。
  • 信号与导航：山里常无信号，离线轨迹必开；烂尾楼附近岔路认清左切，勿沿石溪直下误入溯溪。
  • 过夜：废弃建筑结构与卫生条件未知，结伴、留足电量与饮水；身体不适或天气转坏果断下撤。
  • 停车：兴记尽量早到；盘山接驳路窄，包车沟通好等候点。
  • 环保：无垃圾桶，垃圾全部带走。
