10.30周五 · 后海下班 → 过关 → 大埔墟换乘 → 涌背营地

当日时间轴（约）

  1. 约 18:00–18:30后海下班出发 → 地铁至福田口岸（2 号线转 4 号线，约 35–45 分钟）
  2. 约 19:15–19:45福田口岸过关 → 落马洲站（口岸 06:30–22:00；周五晚一般不堵）
  3. 约 19:45–20:15东铁 落马洲 → 大埔墟（约 30 分钟）
  4. 约 20:20–21:0075K 巴士 大埔墟 → 大美督总站（尾班约 00:00；水粮内地已带，不采购）
  5. 约 21:05–21:50沿新娘潭路步行约 3km → 涌背营地（无路灯，头灯）
  6. 约 21:50扎营 · 自带晚餐

  1. 后海（出发点）

    周五下班出发水粮自带

    露营装备 + 全程水粮内地备好带走（含周六东平洲 2–3L 水/人、干粮零食；香港不采购）。地铁：2 号线（后海 → 市民中心）转 4 号线（市民中心 → 福田口岸），约 35–45 分钟含换乘。

  2. 福田口岸

    06:30–22:00地铁直达

    过关后即落马洲站，东铁往红磡方向约 30 分钟到大埔墟换乘。回程同一口岸出关，地铁回后海。

  3. 大埔墟站 · 换乘

    只换乘不采购

    出站转 75K 往大美督即可；水粮已自带，不在此吃饭/逛超市。东平洲岛上无水源、仅士多少量补给。

  4. 大美督（75K 总站）

    高德可搜「大美督」或「大尾笃」。下车后沿新娘潭路向东北步行约 3km；夜行无路灯，靠左行走。

  5. 住宿 · 涌背营地（渔护署）

    免费 · 免预约无淋浴

    船湾淡水湖旁、新娘潭路边（涌背烧烤场一带）。标准洗手间 + 自来水（水喉在烧烤场旁），无淋浴。先到先得，周五晚到即可；帐篷扎草坪区，风绳打足。无准确 POI，见路线图。

    涌背无准确 POI · 见路线图

10.31周六 · 东平洲环岛 → 贝澳营地

当日时间轴（约）

  1. 约 06:20起床早餐 · 收帐篷
  2. 约 06:50走到涌背烧烤场 20R 站牌候车（别卡点）
  3. 07:15 班20R 乌蛟腾开 → 涌背约 07:20–07:25 上车 → 大埔墟（下一班 08:15，错过必误 09:00 船）
  4. 约 08:00–08:10东铁 大埔墟 → 大学站（2 站）
  5. 约 08:30步行约 15 分钟 → 马料水渡轮码头候船
  6. 09:00翠华渡轮开船（当日唯一去程）→ 约 10:40 抵东平洲
  7. 约 11:00–16:30环岛徒步约 7km：更楼石 → 龙落水 → 斩颈洲 → 洲尾角海蚀平台 → 大塘湾
  8. 17:15返程船（当日唯一一班！）→ 约 18:45 回马料水
  9. 约 19:15–20:15东铁 + 屯马线 + 东涌线 → 东涌站（晚餐可选；水粮已自带）
  10. 约 20:30–21:00屿巴 3M → 贝澳泳滩站，登记处登记扎营
误船预案

SKR 快艇 / 留岛

误 17:15 班船：SKR 快艇约 HK$380/人（约 4 人成团，WhatsApp 90128230 提前约）；或重装留岛过夜——岛上无水源、仅旱厕，一般不建议。

主计划

掐点返程

16:30 结束环岛，16:45 回王爷角码头候 17:15 班船（当日唯一返程）。

  1. 涌背烧烤场（20R 站）

    赶船关键班：07:15下一班 08:15

    营地沿新娘潭路步行数分钟；站名「新娘潭路, 涌背烧烤场」。时刻表按乌蛟腾总站开出（进智公交 PDF / 运输署）：往大埔墟每日 06:15 / 07:15 / 08:15 / 09:15 … 每小时 :15，尾班 20:15。 涌背是途经站，车约晚 5–10 分钟到（07:15 班约 07:20–07:25 到站）。 周六必须上 07:15 这一班——下一班 08:15 到大埔墟约 09:00，必误 09:00 渡轮。 错过：立即步行约 40 分钟回大美督转 75K（班次密），仍可能赶上船；或前一晚踩点站牌。

    路边站牌 · 不链

  2. 大学站

    东铁大埔墟 2 站即到；B 口出站往码头方向步行约 15 分钟。

  3. 马料水渡轮码头

    09:00 唯一去程周末来回 ≈HK$100

    高德搜「马料水码头」或「马料水渡轮码头」。08:30 前到；船票网购（traway.com.hk，周末班次周五 11:00 截止）或现场八达通/现金（不找零），周末排队有错过 09:00 的风险。

  4. 东平洲 · 王爷角码头

    世界地质公园环岛约 7km 平路

    环岛顺/逆时针均可，3–4 小时含拍照：更楼石（海边两层石塔）→ 龙落水（长百米岩脉）→ 斩颈洲（连岛沙洲通道）→ 洲尾角海蚀平台 → 大塘湾（礁石浮潜）。岛上无水源、仅士多少量补给；16:45 前回码头候 17:15 唯一返程船。

    船班即导航 · 不链

  5. 东涌站 · 转屿巴

    转 3M 去贝澳。水粮已自带，不强制采购；饿了可在东荟城一带吃一顿（可选）。

  6. 住宿 · 贝澳营地（康文署）

    免费 · 先到先得有更衣室

    3M 贝澳泳滩站下，登记处登记后扎营；标准洗手间 + 更衣室，营地旁即贝澳泳滩。夜里风大，风绳打足。若满位：退路为 3M 沿线的南山营地 / 长沙上村·下村营地（均免费）。

    登记处现场 · 不链

11.1周日 · 贝澳沙滩 → 大东山日落 → 回后海站收工

当日时间轴（约）

  1. 上午自然醒 · 贝澳/长沙泳滩玩水休整（营地更衣室冲淡）
  2. 约 11:30拔营，3M → 东涌站，行李寄存车站储物柜（以现场为准）
  3. 约 13:00–13:303M 原路返回 → 南山站下车（大东山登山口）
  4. 约 15:00登顶大东山（869m · 11 月芒草正季）
  5. 约 16:30–17:30山顶等日落（11 月初日落约 17:45）
  6. 约 17:45日落后头灯下撤约 1 小时 → 南山
  7. 约 18:45–19:303M 回东涌取行李、晚餐（留意尾班约 19:00–20:00，误了可新界的士回东涌约 HK$80–100）
  8. 约 19:45–21:15东涌线 → 南昌转屯马线 → 大围转东铁 → 落马洲（福田口岸）
  9. 约 21:30–22:15过关 → 地铁回后海站（4→2 号线，约 35–45 分钟）· 路书到此结束，当晚深圳住宿自理

日落版

周六晚住贝澳（沙滩营地），周日睡到自然醒、上午玩水，午后登大东山等 17:45 日落，头灯下撤返程。

  1. 贝澳泳滩

    上午玩水休整；营地更衣室换衣。想换口味可再往西一站到长沙泳滩。

  2. 东涌站 · 寄存行李

    车站自助储物柜（以现场为准）；3M 往返南山从这里出发，回程也在这取行李。

  3. 南山 · 大东山登山口

    3M 南山站下车即登山口（南山营地/南山村旁）；爬升约 450m，石阶多，1.5–2h 登顶。

    3M 中途站 · 不链

  4. 大东山（869m）

    芒草季日落约 17:45

    山顶风大温差大，防风外套 + 长裤；日落前占好机位，日落后头灯下撤。无准确 POI，见路线图。

    高德无可靠 POI · 不链

  5. 落马洲站（福田口岸）

    口岸 22:00 关闭

    21:30 前务必过关——周日大东山日落别拖，天气突变宁可提前下撤。

  6. 后海站 · 路书终点

    收工当晚深圳自理

    出关后地铁 4 号线 → 市民中心转 2 号线到后海站。到站即收工；酒店/回家其余自行安排，路书不再往下写。

预案与备选

风险与预案

  1. 周六东平洲风浪大 → 渡轮或停航：出发前一晚看天文台 + 翠华 FB；停航改西贡桥嘴岛 / 市区行程
  2. 周六晚贝澳满位 → 3M 沿线的南山营地 / 长沙上村·下村营地（均免费）
  3. 误 17:15 返程船 → SKR 快艇约 HK$380/人（4 人成团，WhatsApp 90128230）；或重装留岛（无水源仅旱厕，不建议）
  4. 周日天黑下撤 → 头灯必带；天气突变 16:00 前下撤放弃日落
  5. 周日回程误点 → 福田口岸 22:00 关闭，21:00 前必须离开东涌

备选玩法

  1. 大东山日出版：周六晚改宿南山营地，周日 05:00 摸黑登顶（11.1 日出约 06:25）
  2. 东平洲重装留岛：看星空 + 岛上营地扎营（自备全部水粮）
  3. 大东山天气差：改梅窝骑行 / 贝澳沙滩 + 独木舟
  4. 周五下班过关晚：大埔墟住一晚（约 HK$300），周六直接东平洲

注意事项

  • 香港流量：出发前务必开通（跨境日包 / eSIM）。两晚营地与东平洲无可靠公共 Wi‑Fi；导航、船班、联络全靠手机上网。过关后先测一下能不能连。
