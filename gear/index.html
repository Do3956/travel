鞋袜

抓地与鞋头硬度优先于品牌。

有预算可上迪卡侬 MH100/MH500、凯乐石等一档；跟重不重装无关——现有鞋若抓地够用、鞋头偏硬，继续穿即可。 勿普通运动鞋：易撞石伤趾。

尺码按日常脚长，不必死守「大一码」；厚袜时后跟约一指空隙较舒服。

袜子常被低估：优先美利奴羊毛 / 中长筒排汗袜（勿纯棉）；湿滑段可把旧袜套鞋外增阻、少脏鞋。

背包

日穿轻装与过夜负重档位不同。

  • 日穿 / 轻装：15–25L 双肩小包即可。
  • 过夜：容量 28–40L；25L 塞满偏紧，40L+ 易空荡晃。

看三点：透气背负、硬一点的腰带（负重上胯）、防雨罩。 负重约 15 kg 以内时，艾王（Aione）入门款够用（常见约 200 元内）；再重易勒肩。

想升级：社区常提小鹰（Osprey）或神秘农场（Mystery Ranch，「农场」）；迪卡侬 / 牧高笛入门款也可先顶一趟。

过夜系统

睡袋温度余量 + 垫子隔热，比「品牌齐全」更重要。

睡袋

看「舒适温度」留一点余量。华南十月底山顶夜间多在十来度，烂尾楼 / 风口漏风体感更低，不必按北方严冬备。

防潮垫

蛋巢 / 充气垫二选一，有能力都上。充气垫易被石割，蛋巢可垫底；单蛋巢不够平整。 看 R 值（越高越暖）；充气垫常见推荐「山之泉 R7」（MountainSpring）一类高 R 值款。

帐篷

住建筑废墟 / 有顶营地可不带；野营再上。优先轻量、好搭、防风压桩可靠。

头灯 · 登山杖

头灯：能调焦、续航标称 10h+ 的入门款即可；过夜 / 夜爬务必带备用电池或第二光源。 报团洞穴（如星空洞）可能提供头灯，以当次路书为准。

杖：可折叠外锁，新手先体验再决定要不要碳杖。陡线下行更建议带一对。

衣物分层

排汗 → 保暖 → 防风；纯棉贴身少用。

  • 内层：速干内衣 / 排汗衣
  • 中层：薄抓绒；怕冷再加轻薄羽绒或加厚抓绒
  • 外壳：防风软壳或冲锋衣
  • 下装：速干长裤；陡坡 / 抓绳可加薄手套
  • 营地：拖鞋一双换脚；换洗内裤两条（速干优先）
华南秋冬过夜多数「抓绒 + 防风」够用；漏风建筑再加一层即可，不必一次买齐硬壳体系。

水 · 雨具

无水源山线按路书自备（过夜常见至少约 2.5–3 L / 人起）。有补给点可少带，勿指望小溪。

轻量雨衣或背包防雨罩二选一优先；手机防水袋在潮湿 / 雨天有用。

药 · 急救

  • 创可贴、水泡贴（必带）
  • 止痛药、肠胃药、个人常备药
  • 碘伏棉棒、绷带少量
  • 感冒 / 退烧药按需；驱蚊按季节

哨子、应急箔毯体积小，过夜 / 偏远线建议塞进包底。

采购顺序

整套新购优先「能安全走完」，不必一次品牌齐全。

  1. 鞋 + 袜（抓地、防撞趾）
  2. 头灯 + 水具（过夜 / 夜爬）
  3. 背包（按是否过夜定容量）
  4. 睡袋 + 垫（仅过夜）
  5. 杖、雨具、药包（按线型补齐）
