选购指南 · 小白怎么买

鞋袜类

抓地与鞋头硬度优先于品牌；袜子常被低估。

登山鞋 怎么选 · 注意点

有预算可上迪卡侬 MH100/MH500、凯乐石等一档；跟重不重装无关——现有鞋若抓地够用、鞋头偏硬，继续穿即可。

勿普通运动鞋：易撞石伤趾。尺码按日常脚长，不必死守「大一码」；厚袜试鞋时脚趾轻顶鞋头、脚跟约能插一指较合适（下山不易顶趾）。更多见 防顶趾 / 下坡护脚。

磨合：至少提前约一周穿着（短走 / 通勤），别全新首穿上山——磨脚、起泡多半出在这时。

美利奴袜 怎么选 · 注意点

优先美利奴羊毛 / 中长筒排汗袜；勿纯棉（湿了难干、易磨泡）。比普通薄袜包裹更强，脚在鞋里更稳、少前滑顶趾（见 防顶趾）。

建议两双：路上一双、过夜换一双。中长筒比短袜更护踝、少进沙石。

旧袜套鞋 怎么选 · 注意点

湿滑段可把旧袜套在鞋外：增阻、少脏鞋，几乎零成本。

用穿破、扔掉也不可惜的旧袜即可；干了取下，别当正式鞋套长期穿。

防顶趾 / 下坡护脚 技巧 · 与鞋袜杖配合

陡下坡脚易前冲顶趾；鞋码、系带、步幅、杖、袜一起控。

  • 鞋带系法：高帮——上山可不系上半挂钩（踝活动更自由），下山挂钩全部勒紧锁踝； 低帮——上山顶孔可留空，下山顶孔穿满勒紧固定脚跟。下山前花约 30 秒重系一次。
  • 小步下坡：大步易前滑顶趾、也更伤膝；小步脚趾留空、膝盖更省。
  • 鞋码：试鞋时脚趾顶到鞋头、脚跟能插一指，下山最不易顶趾（与正码 + 一指空余一致）。
  • 双登山杖：下坡分担冲击、身体更稳，减轻脚在鞋内前滑（见 登山杖）。
  • 徒步羊毛袜：比薄袜包裹强，减少滑动顶趾（见 美利奴袜）。
鞋带：下山锁踝 / 锁跟
小步下坡：脚趾省力、护膝
鞋码：顶趾试鞋 + 一指
徒步袜：包裹强、少前滑

负重与过夜

睡袋温度余量 + 垫子隔热，比「品牌齐全」更重要。

背包 怎么选 · 注意点

日穿 / 轻装：15–25L 双肩小包即可。 过夜：容量 28–40L；25L 塞满偏紧，40L+ 易空荡晃。

看三点：透气背负、硬一点的腰带（负重上胯）、防雨罩。 负重约 15 kg 以内时，艾王（Aione）入门款够用（常见约 200 元内）；舒适区间约 7–10 kg，再重易勒肩。自重约 1.1–1.2 kg。

想升级：社区常提小鹰（Osprey）、小高（格里高利 Gregory）或神秘农场（Mystery Ranch，「农场」）； 「小高」即格里高利（口语里「高利格力」多为误听），偏重装贴合与承重；轻装透气常比小鹰。 按背长选尺码、负重试背；迪卡侬 / 牧高笛入门款也可先顶一趟。

睡袋 怎么选 · 注意点

看「舒适温度」留一点余量。华南十月底山顶夜间多在十来度，烂尾楼 / 风口漏风体感更低，不必按北方严冬备。

蛋巢防潮垫 怎么选 · 注意点

闭孔泡沫蛋巢：轻、耐扎、可垫在充气垫下防割。单用时平整度一般，体感偏硬。

看厚度与 R 值（越高越暖）；预算紧或怕充气垫漏气时，先上蛋巢最稳妥。

充气垫 怎么选 · 注意点

睡感更平更暖，但易被石割；有能力可与蛋巢同带（蛋巢垫底）。

重点看 R 值；常见推荐「山之泉 R7」（MountainSpring）一类高 R 值款。过夜前练打气 / 收纳。

帐篷 怎么选 · 注意点

住建筑废墟 / 有顶营地可不带；野营再上。优先轻量、好搭、防风压桩可靠。

追求轻量化可选塔帐：如「蓝山一」本体约 800 g，加上地钉、风绳等全部附件整包 1 kg 内（约 1–2 斤）；对比现在常用的帐篷 2.5 kg（5 斤），能省下大半重量。

保养：

  • 不要机洗 / 机烘：洗衣机搅动易伤布、缝线与防水涂层；脏了用海绵或手在冷 / 温水里轻擦，中性皂或户外专用洗剂，忌洗衣粉、漂白、大力搓。
  • 阴凉处彻底晾干再收（防霉、防涂层发黏）；少长时间暴晒。外帐泼水变差时，可喷补防水层（DWR 喷雾 / 养护液，网上有卖），洗后一般需重新做防水。

防护与其它

照明、助行、衣物分层、水雨与急救，按线型补齐。

头灯 怎么选 · 注意点

能调焦、续航标称 10h+ 的入门款即可；过夜 / 夜爬务必带备用电池或第二光源。

报团洞穴（如星空洞）可能提供头灯，以当次路书为准。

登山杖 怎么选 · 注意点

可折叠外锁；新手先体验再决定要不要碳杖。陡线下行更建议带一对：分担冲击、减前滑顶趾（见 防顶趾）。

双杖下坡：分担冲击、脚趾更轻松

髌骨带 怎么选 · 注意点

何时需要：长陡下坡（如戈见山 / 大南山一类）、膝有旧伤或不适、负重偏大时，下坡刹车力容易顶到髌腱。膝盖完全没症状可先不买，优先杖 + 控速。

窄带压在髌骨下方（髌腱一带），针对膝前 / 髌腱酸痛；不是把整个膝盖包起来。选开合可调、走动不勒麻；有症状再戴，别整晚勒着睡觉。

护膝套 怎么选 · 注意点

与髌骨带不同：套筒包覆整膝，靠压迫 + 保暖减轻笼统酸胀、轻微肿胀、想多一点「稳定感」时更合适；不专门针对髌腱点压。

同样建议开合 / 尺寸可调，贴合但不妨碍屈伸、无麻木；有症状或已知弱膝再戴，别当万能护具整夜加压。严重不稳、绞锁、肿胀加重应停走就医，护具不能替代训练与杖。

速干内衣 怎么选 · 注意点

内层用速干内衣 / 排汗衣；纯棉贴身少用（湿透难干、易失温）。

抓绒 怎么选 · 注意点

中层保暖：薄抓绒即可；怕冷再加轻薄羽绒或加厚抓绒。

华南秋冬过夜多数「抓绒 + 防风」够用；漏风建筑再加一层，不必一次买齐硬壳体系。

防风壳 怎么选 · 注意点

外壳用防风软壳或冲锋衣，挡风比「看起来厚」更重要。

保养：

  • 冲锋衣 / 硬壳：勿当「绝对不能洗」；普通洗衣粉、柔顺剂会伤表层防泼水（DWR）。新手可手洗；标签允许时也可用专用「技术洗」+ 轻柔 / 低温、低转速单独机洗（波轮摩擦大更宜手洗）。
  • 洗后若水珠不再成珠滚落，需补防水：喷雾或洗护液（Nikwax / Granger's 一类，国内网购常见），先洗净再涂。部分款低温烘干可助 DWR 回活，以吊牌为准。

手套 怎么选 · 注意点

陡坡 / 抓绳可加薄手套，护手、少磨破皮。不必先买专业攀岩手套。

一次性内裤 怎么选 · 注意点

短途过夜可用针织贴合一次性：当天穿一条、再带一条换。有速干内裤更好。

营地拖鞋 怎么选 · 注意点

到营地换脚，让登山鞋通风；轻量、能塞包侧袋即可。

水杯 / 饮水 怎么选 · 注意点

无水源山线按路书自备（过夜常见至少约 2.5–3 L / 人起）。有补给点可少带，勿指望小溪。

硬水瓶 + 软水袋皆可；软袋省空间，硬瓶更好灌 / 加电解质。

雨具 怎么选 · 注意点

轻量雨衣或背包防雨罩二选一优先；手机防水袋在潮湿 / 雨天有用。

药品 怎么选 · 注意点

创可贴、水泡贴必带；止痛药、肠胃药、个人常备药按需。碘伏棉棒、绷带少量；感冒 / 退烧药按需，驱蚊按季节。

体温计 怎么选 · 注意点

优先电子：快、耐摔、夜里好读。玻璃酒精 / 镓铟款无电池，但易碎、要测几分钟。

哨子 · 箔毯 怎么选 · 注意点

体积小、重量轻；过夜 / 偏远线建议塞进包底，应急求救与保暖。

衣物原则：排汗 → 保暖 → 防风。华南多数线「抓绒 + 防风」够用，漏风建筑再加一层即可。

采购顺序

整套新购优先「能安全走完」，不必一次品牌齐全。

  1. 登山鞋 + 美利奴袜（抓地、防撞趾）
  2. 头灯 + 水杯 / 饮水（过夜 / 夜爬）
  3. 背包（按是否过夜定容量）
  4. 睡袋 + 蛋巢 / 充气垫（仅过夜）
  5. 登山杖、雨具、药品与体温计（按线型补齐）

二手、折扣装备可在闲鱼、拼多多淘一下；看好成色、真伪与尺码即可。
